## Contract pins (from apps/api/src/cricai_api/routers)

| Router | Endpoint | Roles | Response |
|---|---|---|---|
| pipeline | `GET /pipeline/sessions/{id}/runs` | parent, coach | `RunSummaryOut[]` {id, session_id, status: StageStatus, started_at, finished_at} |
| pipeline | `GET /pipeline/runs/{run_id}` | parent, coach | `RunDetailOut` {id, session_id, status, detector_context, started_at, finished_at, stages: StageAttemptOut[]} |
| pipeline | `POST /pipeline/sessions/{id}/runs` and `/resume` | parent | `RunOut` {run_id, session_id, status, stages: StageOutcomeOut[]}; 409 when locked |
| pipeline | `POST /pipeline/sessions/{id}/rederive` | parent | `RederiveOut`; 409 `{message, blockers}` when manual rows exist |
| wellness | `GET /wellness/{player}/checkins?start&end` | all | `CheckinOut[]` |
| wellness | `POST /wellness/{player}/checkins` | all | `CheckinOut`; 422 detail = problems list |
| wellness | `POST /wellness/{player}/checkins/{id}/clearance` | parent, coach | `ClearanceOut` |
| wellness | `GET /wellness/{player}/state?as_of` | all | `WellnessStateOut` |
| alerts | `GET /alerts?audience&acknowledged` | parent, coach | `AlertOut[]` newest first |
| alerts | `POST /alerts/{id}/ack` | parent, coach | `AlertOut` |
| cameras | `GET /cameras?include_history&role` | all (route table: parent page) | `CameraOut[]` |
| cameras | `PATCH /cameras/{camera_id}` `{role}` | parent | `CameraOut` |
| health-checks | `GET /health-checks?session_id` | all | `HealthCheckRecordOut[]` newest first; `results.checks[]` = {name, passed, detail} |
| settings | `GET /settings`, `GET /settings/versions` | parent, coach (route table: parent page) | `AppSettingsOut` |
| settings | `POST /settings` `{settings, reason}` | parent, coach with per-field gates | `AppSettingsOut`; 403 detail names the missing approval; 409 on version race |

Enums: StageStatus pending/running/succeeded/failed/skipped; AlertAudience parent/developer;
CameraRole batting_side/bowling_side/wrist/front_on/other; ReviewMode auto_publish/coach_gate.
Pipeline stage order: probe, calibrate_check, events, clips, pose, detect_track, metrics,
bowling_action, bowling_flight, classify_variations, analysis, progress, planner, safety, report.
